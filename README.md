# Personal Portfolio Website 🚀

A responsive developer portfolio built using React, showcasing my experience, skills, and projects in web and mobile development.

## Features

- Responsive modern UI
- Professional experience section
- Skills showcase
- Downloadable resume
- Contact section with social links
- Clean and reusable component-based architecture

## Tech Stack

- React
- JavaScript
- HTML/CSS
- Responsive Design

## Project Structure

```bash
src/
├── components/
│   ├── Header.js          # Navigation and section links
│   ├── IntroSection.js            # Introduction with intro
│   ├── Experience.js      # Professional experience
│   ├── Skills.js          # Skills showcase
│   └── Contact.js         # Contact information
├── styles/
│   ├── global.css         # Global styles and CSS variables
│   ├── Header.css
│   ├── IntroSection.css
│   ├── Experience.css
│   ├── Skills.css
│   └── Contact.css
├── constants.js           # Portfolio data (name, links, etc.)
├── App.js                 # Main app component
└── index.js               # Entry point
```

## Getting Started

### Clone the repository

```bash
git clone <your-repository-url>
```

### Install dependencies

```bash
npm install
```

### Start development server

```bash
npm start
```

## Build for Production

```bash
npm run build
```

## Customization

You can easily update:

- Personal details
- Skills
- Experience
- Social links
- Resume
- Profile image

through the `constants.js` file and component sections.
